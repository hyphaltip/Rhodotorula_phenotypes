# Database design

Rewritten 2026-10-08. The earlier design (dimension tables, `colony_measurement`, `v_phenotype`) is retired; see `scripts/db/RETIRED.md`. The column list is in `SCHEMA.md` (generated: `scripts/db/40_data_dictionary.py`).

## Location and rebuild
- File: `db/rhodotorula_phenotypes.duckdb` (not tracked in git).
- Rebuild with `pixi run python scripts/db/25_import_heavy_metal.py` through SLURM. The script is idempotent. It also runs `35_create_strain_view.sql`. Check with `scripts/db/check_heavy_metal_db.py`.
- Inputs: Parquet files `data/preprocessed/heavy_metal_array/{Chromium,Copper,Iron,Lead,Zinc}.parquet` (made by `scripts/ingest/heavy_metal_csv_to_parquet.py`) and `data/metadata/strain-curation/strain_curation.csv`.

## Tables
| Object | Kind | Content |
|---|---|---|
| `heavy_metal_measurement` | table | One row per colony per image, all five metals, unioned by column name. `Metal` names the source file. 32 columns exist only for Lead and Zinc (NULL elsewhere). |
| `strain_curation` | table | One row per phenotyped strain (321). Corrected species, ploidy status, popgen group membership, identity flags, GWAS eligibility, de-clone groups. Generated by `scripts/curation/build_strain_curation.py`. |
| `metal_source_status` | table | Per-metal data status. Iron and Zinc are `incomplete_source` (D-56). |
| `strain_info` | view | One row per strain, from `heavy_metal_measurement` joined to `strain_curation`. Species, ploidy and GWAS flags come from the curation table; `species_screen` keeps the original value. Controls (`Control-N`) have no curation row. |
| `strain_metal_status` | view | One row per strain and metal, with the source status. Filter on it to hold out Fe and Zn. |

## Conventions
- `strain_id` is VARCHAR: numeric ids for strains, `Control-N` for controls. 10,921 colony rows have NULL `strain_id` and belong to no strain.
- `ploidy_status` values: haploid, diploid_hybrid, diploid_other, unknown.
- `gwas_panel` is true for 126 strains: haploid *R. mucilaginosa* in popgen `rmuc_core`, no identity flag, one representative per group of at most 5 SNPs (D-49).
- Species, ploidy and panel changes are never made in the database. Edit the rules in the generator, regenerate the CSV and rebuild.
- Decisions: D-34, D-35, D-37, D-45 to D-49, D-54 to D-56, D-58 in `.living/decisions.md`.
